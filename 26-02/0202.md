## 1단계 - name 뽑아내기

- 집계함수 중첩은 안됨
```
SELECT
    MAX(count(u.name)) AS result
FROM MovieRating m
INNER JOIN Users u
ON u.user_id = m.user_id
GROUP BY m.user_id
ORDER BY u.name ASC
LIMIT 1 ;

<error>
Invalid use of group function
```
> "어? MAX 안에 COUNT를 넣었네? 이건 집계 함수를 중첩(nesting)한 건데...
> SQL에서는 집계 함수 안에 집계 함수를 직접 못 넣어.

<br><br>

### Rule.SELECT에 있는 모든 non-aggregate 컬럼을 GROUP BY에 포함하라
> "음... GROUP BY u.user_id로 그룹을 만들었어.  
> user_id = 1인 그룹에는 3개의 row가 있네.  
> COUNT(*)는 3이야. 좋아.   
> 그런데 잠깐... SELECT에 u.name이 있잖아?  
> user_id = 1 그룹에 있는 3개 row의 name 값은 모두 'Daniel'이야.  
> 하지만 내가 어떻게 알아?  
> user_id와 name이 1:1 관계라는 보장이 있어?  
> 만약 user_id = 1인데 name이 'Daniel', 'David', 'Dave' 이렇게 3개 다르면?  
> 어떤 name을 보여줘야 하지? 첫 번째? 마지막? 랜덤?  
> 이건 모호해! 에러 발생!"

<br> 

```
SELECT u.user_id, u.name, COUNT(*) as rating_count

expected result:
```

```
그룹 1을 보면:
```

### ORDER BY에서 집계함수 사용 가능하다. 
> 어렸웠던게 SELECT에서 COUNT하고 높은거 하나 출력하기 위해서  
> MAX(COUNT(*)) 이렇게 했었는데, 그냥 ORDER BY에서 COUNT함수 사용할 수 있으니까 높은순으로 정렬하고  
> LIMIT 1 때리면 최대값만 출력할수 있음. !!
> 사실 이게 가장 큰 문제였다.

- 조건1 쿼리 완성
```
SELECT u.name
FROM MovieRating mr
INNER JOIN Users u
ON mr.user_id = u.user_id
GROUP BY mr.user_id, u.name
ORDER BY COUNT(*) DESC , u.name ASC
LIMIT 1;


| name   |
| ------ |
| Daniel |
```

## 2단계 - 2월 평균 평점이 가장 높은 영화 뽑기
> 동일하게 ORDER BY에서 집계함수 써주면 간단히 해결됨  
```
SELECT m.title
FROM MovieRating mr
INNER JOIN Movies m
ON mr.movie_id = m.movie_id
WHERE YEAR(mr.created_at) = 2020
AND MONTH(mr.created_at) = 2
GROUP BY mr.movie_id, m.title
ORDER BY AVG(mr.rating) DESC, m.title ASC
Limit 1;

| title    |
| -------- |
| Frozen 2 |
```
<br> 


- 좀더 개선해볼까 WHERE절이 있으면 서브쿼리로 스캔범위 줄여주면 더 빠를듯?!

> "서브쿼리로 스캔 범위를 줄인다는 아이디어는 좋은데...  
> 실제로는 현재 쿼리가 이미 최적화되어 있을 가능성이 높아.  
> 왜냐하면 WHERE 절이 JOIN 전에 먼저 필터링되거든.  

> 쉽게말해서 서브쿼리안해도 얘가 알아서 필터링해서 JOIN절 실행한다는거지?
> 네, 맞아요. MySQL 옵티마이저가 알아서 WHERE 절을 먼저 실행해서 필터링한 다음 JOIN해."
```
-- 실행순서
SELECT          -- 1. 우리가 첫 번째로 씀
FROM            -- 2. 
JOIN            -- 3. 
WHERE           -- 4. 
GROUP BY        -- 5. 
HAVING          -- 6. 
ORDER BY        -- 7. 
LIMIT           -- 8. 우리가 마지막으로 씀


-- MySQL이 실제로 실행하는 순서:
FROM            -- 1. 실제로 제일 먼저 실행
JOIN            -- 2. 
WHERE           -- 3. 
GROUP BY        -- 4. 
HAVING          -- 5. 
SELECT          -- 6. 
ORDER BY        -- 7. 
LIMIT           -- 8. 실제로 마지막 실행

```

### 3단계 - UNION절로 합치기
- UNION vs UNION ALL
- UNION: 중복 제거 위해 정렬 작업 수행 (느림)
- UNION ALL: 중복 제거 안 함 (빠름)

```

(
    SELECT u.name AS results
    FROM MovieRating mr
    JOIN Users u ON mr.user_id = u.user_id
    GROUP BY u.user_id, u.name
    ORDER BY COUNT(*) DESC, u.name ASC
    LIMIT 1
)

UNION ALL


(
    SELECT m.title AS results
    FROM MovieRating mr
    JOIN Movies m ON mr.movie_id = m.movie_id
    WHERE YEAR(mr.created_at) = 2020 AND MONTH(mr.created_at) = 2
    GROUP BY mr.movie_id, m.title
    ORDER BY AVG(mr.rating) DESC, m.title ASC
    LIMIT 1
)
```

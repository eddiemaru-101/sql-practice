> 모든 물건을 구매한에서 힌트를 얻어서,, 스칼라 서브쿼리로 해결하려고 CTE를 사용하면 되겠다 했지만 1트 실패!

## 1단계 - 모든 물건 수 구하기
> 왜 에러 뜨는거지??

```
WITH product_sum AS (
    SELECT count(product_key) 
    FROM Product
    ) 
SELECT 
    IF(count(product_key)=product_sum,cutomer_id, null) AS customer_id
FROM Customer c
GROUP BY c.customer_id;

<error>
Unknown column 'product_sum' in 'field list'
```
### CTE에 대한 이해가 부족했다.
```
WITH product_sum AS (
    SELECT count(product_key) 
    FROM Product
    ) 
```
- 문제1.CTE는 테이블이고, SELECT문의 "count(product_key)" 을 사용하려면 컬럼명을 지정해야 사용가능하다.
- 문제2.IF문에서 product_sum는 테이블이다. product_sum의 필드를 사용해야한다. 
  - `IF(count(product_key)=product_sum,cutomer_id, null) AS customer_id`
<br><br>
<br><br> 



## 2단계 - CTE 에러 수정
> CTE 에러 수정하고, IF문으로 다시 테이블간 필드명 명시적으로 잘 나타내었다.  
> 하지만 IF조건 불만족시, NULL값 반환했더니 NULL이 포함되어 나오네...  
- CTE 사용할땐 CROSS JOIN 하거나 FROM절에 CTE테이블명을 넣어야 사용이 가능하다. (CROSS-JOIN,WHERE절 두개 동일한 작업임)
- CROSS-join 형태로 테이블을 보면..  
```
WITH product_sum AS (
    SELECT COUNT(product_key) AS total_prod_sum
    FROM Product
) 
SELECT 
    *
FROM Customer c
CROSS JOIN product_sum
GROUP BY c.customer_id;


| customer_id | product_key | total_prod_sum |
| ----------- | ----------- | -------------- |
| 1           | 5           | 2              |
| 2           | 6           | 2              |
| 3           | 5           | 2              |
```
<br>
  
- 쿼리에 적용하면, 
```
WITH product_sum AS (
    SELECT COUNT(product_key) AS total_prod_sum
    FROM Product
) 
SELECT 
    IF(COUNT(DISTINCT c.product_key) = product_sum.total_prod_sum, c.customer_id, NULL) AS customer_id
FROM Customer c
CROSS JOIN product_sum
GROUP BY c.customer_id;

<result>
| customer_id |
| ----------- |
| 1           |
| null        |
| 3           |

<Expected>
| customer_id |
| ----------- |
| 1           |
| 3           |
```
> 여기서 문제는, if문에서 조건을 만족하지 않으면 pass같은 문법이 없어. null을 반환하든 뭐든 값을 무조건 반환해야함  
> 그래서 if문이 아닌 다른 방법을 사용해야함
> GROUP BY하고 필터링 걸어야함(HAVING)

<br><br>


## 3단계 - Having절로 모든 물건을 산 사람을 필터링하자 
> HAVING절에서 GROUP BY 의 함정에 빠짐. 그러나 여기서는 에러가 남

```
WITH product_sum AS (
    SELECT COUNT(product_key) AS total_prod_sum
    FROM Product
) 
SELECT 
    customer_id
FROM Customer c
CROSS JOIN product_sum p
GROUP BY c.customer_id
HAVING COUNT(DISTINCT product_key) = p.total_prod_sum;

<error>
- Unknown column 'p.total_prod_sum' in 'having clause'
```
- HAVING절에서 p.total_prod_sum은 하나가 아님. CROSS-JOIN되어서 여러 레코드를 가진 값이므로 동일하게 집계함수로 표현해야함.
- 수정하면..

```
#정답쿼리

WITH product_sum AS (
    SELECT COUNT(product_key) AS total_prod_sum
    FROM Product
) 
SELECT 
    customer_id
FROM Customer c
CROSS JOIN product_sum p
GROUP BY c.customer_id
HAVING COUNT(DISTINCT product_key) = MAX(p.total_prod_sum);

<result>
| customer_id |
| ----------- |
| 1           |
| 3           |
```
<br><br> 

## 4단계 - 좀 더 간단하게 푸는 다른 방법 
> 풀면서 가장 큰 문제였던건, CTE를 스칼라 서브쿼리처럼 사용하겠다는 잘못된 생각이었고,  
> CTE를 사용하면 CROSS-JOIN을 사용해서 불필요한 JOIN이 발생한다는 점이다.
> 단순 스칼라 서브쿼리로 풀어보자 !
- 스칼라서브쿼리 적용
```
# 정답쿼리
SELECT 
    customer_id
FROM Customer
GROUP BY customer_id
HAVING COUNT(DISTINCT product_key) = (SELECT COUNT(product_key) FROM Product);

<result>
| customer_id |
| ----------- |
| 1           |
| 3           |
```
> 너무 쉽게 풀리네..

# 1045. Customers Who Bought All Products
```
Table: Customer

+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| customer_id | int     |
| product_key | int     |
+-------------+---------+
This table may contain duplicates rows. 
customer_id is not NULL.
product_key is a foreign key (reference column) to Product table.
 

Table: Product

+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| product_key | int     |
+-------------+---------+
product_key is the primary key (column with unique values) for this table.
 

Write a solution to report the customer ids from the Customer table that bought all the products in the Product table.

Return the result table in any order.

The result format is in the following example.

 

Example 1:

Input: 
Customer table:
+-------------+-------------+
| customer_id | product_key |
+-------------+-------------+
| 1           | 5           |
| 2           | 6           |
| 3           | 5           |
| 3           | 6           |
| 1           | 6           |
+-------------+-------------+
Product table:
+-------------+
| product_key |
+-------------+
| 5           |
| 6           |
+-------------+
Output: 
+-------------+
| customer_id |
+-------------+
| 1           |
| 3           |
+-------------+
Explanation: 
The customers who bought all the products (5 and 6) are customers with IDs 1 and 3.
```

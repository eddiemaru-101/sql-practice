## 2단계 - 맨마지막 id 찾기
> 마지막 id만 다르게 처리해줘야한다.
> 어떻게 마지막 id를 찾을까?
- 마지막 id찾기
```
1. SELECT COUNT(*)
2. MAX(id)


-- 1.MySQL 옵티마이저가 한 번만 실행하도록 최적화함 (보장은 아님)
WHEN id < (SELECT COUNT(*) FROM Seat)
-- 2.MAX함수
WHEN id%2 = 1 AND id < (SELECT MAX(id) FROM Seat) THEN id + 1
```

흠...
### 집계함수 사용조건
```
-- 이런 집계 함수들은
MAX(), MIN(), COUNT(), SUM(), AVG()

-- 두 가지 컨텍스트에서만 사용 가능:
1. SELECT 절에서 단독으로
2. GROUP BY와 함께
3. HAVING 절에서

-- WHERE나 CASE의 조건부에서는 직접 사용 불가!
-- ON절에서도 안됨 
```
```
SELECT
    CASE 
        WHEN id%2 = 1 AND id < MAX(id)  THEN  id + 1
        WHEN id%2 = 1 THEN id
        ELSE id - 1
        END AS id
    ,student
FROM Seat
ORDER BY id ASC;

| id | student |
| -- | ------- |
| 2  | Abbot   |
```
- 결과는 나오는데 이상한데?
- "딱 1개 row만 나왔네. 이건 암묵적 GROUP BY가 발생한 거야."
- 그룹바이를 그냥 테이블 전체에 적용해서 1개 레코드로 했다는 말 .
```
-- 내부적으로 이렇게 해석됨
SELECT ... 
FROM Seat 
GROUP BY ();  -- 빈 GROUP BY = 전체를 1개 그룹으로

- 5개 row → 1개 row로 축소
- 각 컬럼에서 임의의 값 하나씩 선택
- MAX(id)는 전체에서 계산
```

- 이제 제대로 작성하면,
### 정답쿼리
```
SELECT
    CASE 
        WHEN id%2 = 1 AND id < (SELECT MAX(id) FROM Seat) THEN  id + 1
        WHEN id%2 = 1 THEN id
        ELSE id - 1
        END AS id
    ,student
FROM Seat
ORDER BY id ASC;


| id | student |
| -- | ------- |
| 1  | Doris   |
| 2  | Abbot   |
```

# 626. Exchange Seats
```
Table: Seat

+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| id          | int     |
| student     | varchar |
+-------------+---------+
id is the primary key (unique value) column for this table.
Each row of this table indicates the name and the ID of a student.
The ID sequence always starts from 1 and increments continuously.
 

Write a solution to swap the seat id of every two consecutive students. If the number of students is odd, the id of the last student is not swapped.

Return the result table ordered by id in ascending order.

The result format is in the following example.

 

Example 1:

Input: 
Seat table:
+----+---------+
| id | student |
+----+---------+
| 1  | Abbot   |
| 2  | Doris   |
| 3  | Emerson |
| 4  | Green   |
| 5  | Jeames  |
+----+---------+
Output: 
+----+---------+
| id | student |
+----+---------+
| 1  | Doris   |
| 2  | Abbot   |
| 3  | Green   |
| 4  | Emerson |
| 5  | Jeames  |
+----+---------+
Explanation: 
Note that if the number of students is odd, there is no need to change the last one's seat.
```

> 흠.. 이건 누적합을 구해야하는데 ...   
> 그래서 윈도우 함수를 사용하는 걸로 접근했다.  


## 1단계 - 누적합 구하기(윈도우함수)
> 레코드끼리 합을 구해야해서 계속 셀프조인으로 해야하나? 생각했지만 1000킬로라는 조건에 도달할 때까지 이므로
> 이건 윈도우 함수를 사용해야겠다고 생각했다. 윈도우 함수가 이럴때 쓰인다는걸 알게 됨

```
SELECT 
    person_name
    ,weight
    ,SUM(weight) OVER (
        ORDER BY turn ASC
    ) AS weight_sum
FROM Queue;


| person_name | weight | weight_sum |
| ----------- | ------ | ---------- |
| Alice       | 250    | 250        |
| Alex        | 350    | 600        |
| John Cena   | 400    | 1000       |
| Marie       | 200    | 1200       |
| Bob         | 175    | 1375       |
| Winston     | 500    | 1875       |
```
<br><br> 

## 2단계 - 조건으로 필터링 
> 어렵네..
> 일단 SELECT문에서 weight_sum이 발생한거라 CTE로 테이블 정의 하고 필터링 새로 걸어야한다.
> 1000킬로 이하인 사람중에 turn값이 최대인 사람 뽑으려고 WHERE절을 사용하려다가 MAX함수를 사용할수 없어서 실패..
> 다르게 접근해야만 했다.

- WHERE절에 MAX쓰려고한 잘못된 쿼리 
```
WITH weight_table AS (
    SELECT 
        turn
        ,person_name
        ,weight
        ,SUM(weight) OVER (
            ORDER BY turn ASC
        ) AS weight_sum
    FROM Queue
    )
SELECT
    *
FROM weight_table
WHERE weight_sum <= 1000 
    AND MAX(turn)  --여기가 잘못됨.
```
<br> 

- 접근법을 바꿔서, ORDER BY 하고 LIMIT로 1개 남기기(맨위 하나만 남김)

```
WITH weight_table AS (
    SELECT 
        turn
        ,person_name
        ,weight
        ,SUM(weight) OVER (
            ORDER BY turn ASC
        ) AS weight_sum
    FROM Queue
    )
SELECT
    *
FROM weight_table
WHERE weight_sum <= 1000 
ORDER BY turn DESC
LIMIT 1;


| turn | person_name | weight | weight_sum |
| ---- | ----------- | ------ | ---------- |
| 3    | John Cena   | 400    | 1000       |
```
> 오, 하나만 남았다.

## 3단계 - 정답쿼리
```
WITH weight_table AS (
    SELECT 
        turn
        ,person_name
        ,weight
        ,SUM(weight) OVER (
            ORDER BY turn ASC
        ) AS weight_sum
    FROM Queue
    )
SELECT
    person_name
FROM weight_table
WHERE weight_sum <= 1000 
ORDER BY turn DESC
LIMIT 1;


| person_name |
| ----------- |
| John Cena   |
```

# 1204. Last Person to Fit in the Bus
```
Table: Queue

+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| person_id   | int     |
| person_name | varchar |
| weight      | int     |
| turn        | int     |
+-------------+---------+
person_id column contains unique values.
This table has the information about all people waiting for a bus.
The person_id and turn columns will contain all numbers from 1 to n, where n is the number of rows in the table.
turn determines the order of which the people will board the bus, where turn=1 denotes the first person to board and turn=n denotes the last person to board.
weight is the weight of the person in kilograms.
 

There is a queue of people waiting to board a bus. However, the bus has a weight limit of 1000 kilograms, so there may be some people who cannot board.

Write a solution to find the person_name of the last person that can fit on the bus without exceeding the weight limit. The test cases are generated such that the first person does not exceed the weight limit.

Note that only one person can board the bus at any given turn.

The result format is in the following example.

 

Example 1:

Input: 
Queue table:
+-----------+-------------+--------+------+
| person_id | person_name | weight | turn |
+-----------+-------------+--------+------+
| 5         | Alice       | 250    | 1    |
| 4         | Bob         | 175    | 5    |
| 3         | Alex        | 350    | 2    |
| 6         | John Cena   | 400    | 3    |
| 1         | Winston     | 500    | 6    |
| 2         | Marie       | 200    | 4    |
+-----------+-------------+--------+------+
Output: 
+-------------+
| person_name |
+-------------+
| John Cena   |
+-------------+
Explanation: The folowing table is ordered by the turn for simplicity.
+------+----+-----------+--------+--------------+
| Turn | ID | Name      | Weight | Total Weight |
+------+----+-----------+--------+--------------+
| 1    | 5  | Alice     | 250    | 250          |
| 2    | 3  | Alex      | 350    | 600          |
| 3    | 6  | John Cena | 400    | 1000         | (last person to board)
| 4    | 2  | Marie     | 200    | 1200         | (cannot board)
| 5    | 4  | Bob       | 175    | ___          |
| 6    | 1  | Winston   | 500    | ___          |
+------+----+-----------+--------+--------------+
```
